# Security

The library does arithmetic on the numbers you pass in. The demo page renders text from its URL, so an injection bug there would be a real vulnerability.

Report one through GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on this repository. If the form is unavailable, open an issue without the details and ask for a private channel.
