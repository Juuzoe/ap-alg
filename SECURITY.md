# Security

The library only does arithmetic on the numbers passed to it. The demo page renders text from its URL, so an injection bug there would be a real issue.

Report a vulnerability privately with GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on this repository. If that option is not available, open an issue that says you have found one, without the details, and the maintainer will set up a private channel.
